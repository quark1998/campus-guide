# 自研校园导航准确性优化说明

本版重点修复两类常见不准问题：

1. 坐标系统一为 GCJ02：Android 高德定位、地标坐标、后台路网节点使用同一套坐标数值，不再在 Android 端进行 GCJ02/WGS84 转换，避免路线整体偏移。
2. 起终点道路吸附：后端 `/api/nav/routeByLocation` 不再把当前位置直接吸附到最近节点，而是吸附到最近道路边的投影点，并把投影点作为临时虚拟节点接入路网。

使用建议：

- 后台路网节点应沿真实道路绘制，不要只在建筑物中心放点。
- 每个路口、拐点、道路转弯处都要添加节点。
- 每条可通行道路都需要连线，不能只放节点。
- 起点或终点吸附距离超过 80 米时，说明该区域附近道路节点不足，应在后台补充道路。
